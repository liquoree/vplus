# Vezdehod+ Karelia

Frontend-часть сайта компании [«Вездеход+ Карелия»](https://vezdehod-plus.ru), занимающейся арендой техники для активного отдыха.

Данный репозиторий содержит клиентскую часть корпоративного сайта. Проект представляет собой современный лендинг-сайт с серверным рендерингом, разработанный для представления услуг компании и удобного взаимодействия пользователей с сайтом.

## Возможности

- Адаптивный пользовательский интерфейс
- Серверный рендеринг с использованием Next.js
- Представление информации об услугах компании
- Интерактивные элементы сайта
- Оптимизированная загрузка страниц

## Технологии

Next.js, React, TypeScript, SCSS, Axios

# Vezdehod+ Karelia

Frontend part of the website for [Vezdehod+ Karelia](https://vezdehod-plus.ru), an outdoor equipment rental company.

This repository contains the client-side part of the corporate website. The project is a modern landing website with server-side rendering, developed to showcase the company's services and provide a convenient user experience.

## Features

- Responsive user interface
- Server-side rendering with Next.js
- Company service presentation
- Interactive website elements
- Optimized page loading

## Technologies

Next.js, React, TypeScript, SCSS, Axios
